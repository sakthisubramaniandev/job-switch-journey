## 1. String Methods

### Why String Methods?
Strings are everywhere — interviews, real projects, LeetCode.
Must know these cold!

### Most Important Methods:
```python
text = "  Hello World Python  "

# Case methods
text.upper()        # "  HELLO WORLD PYTHON  "
text.lower()        # "  hello world python  "
text.title()        # "  Hello World Python  "
text.swapcase()     # "  hELLO wORLD pYTHON  "

# Strip methods — remove whitespace
text.strip()        # "Hello World Python"
text.lstrip()       # "Hello World Python  "
text.rstrip()       # "  Hello World Python"

# Search methods
text.find("World")      # 8 (index) or -1 if not found
text.count("l")         # 3
text.startswith("  H")  # True
text.endswith("  ")     # True
"World" in text         # True

# Replace
text.replace("World", "Sakthi")
# "  Hello Sakthi Python  "

# Split and Join
sentence = "Hello World Python"
words = sentence.split(" ")   # ['Hello', 'World', 'Python']
joined = "-".join(words)      # "Hello-World-Python"
```

### Most Useful for LeetCode:
```python
s = "hello world"

# Split into words
words = s.split()         # ['hello', 'world']

# Check alphanumeric
"abc123".isalnum()        # True
"abc 123".isalnum()       # False (space!)

# Check all digits
"123".isdigit()           # True
"12.3".isdigit()          # False

# Check all letters
"abc".isalpha()           # True
"abc1".isalpha()          # False

# Strip specific character
"###hello###".strip("#")  # "hello"

# Convert to list of chars
list("hello")             # ['h','e','l','l','o']

# Reverse a string
"hello"[::-1]             # "olleh"
```

### String Slicing:
```python
s = "Hello World"
#    01234567890

s[0]      # H (first char)
s[-1]     # d (last char)
s[0:5]    # Hello (index 0 to 4)
s[6:]     # World (index 6 to end)
s[:5]     # Hello (start to index 4)
s[::2]    # HloWrd (every 2nd char)
s[::-1]   # dlroW olleH (reversed!)
```

## 2. Regular Expressions

### What is Regex?
A way to find patterns in strings.
Used for validation, searching, replacing.

### Import:
```python
import re
```

### Basic Patterns:
| Pattern | Meaning |
|---|---|
| `.` | Any character |
| `*` | Zero or more |
| `+` | One or more |
| `?` | Zero or one |
| `\d` | Digit (0-9) |
| `\w` | Word character |
| `\s` | Whitespace |
| `^` | Start of string |
| `$` | End of string |
| `{n}` | Exactly n times |

### Most Used Functions:
```python
import re

# re.findall → find ALL matches → returns list
matches = re.findall(r'\d+', "I have 3 cats and 2 dogs")
print(matches)  # ['3', '2']

# re.match → match at START of string only
result = re.match(r'Hello', "Hello World")
print(result)   # Match object ✅

result = re.match(r'World', "Hello World")
print(result)   # None — not at start! ❌

# re.search → find ANYWHERE in string
result = re.search(r'World', "Hello World")
print(result)   # Match object ✅

# re.sub → replace matches
result = re.sub(r'\s+', '-', "Hello World Python")
print(result)   # "Hello-World-Python"
```

### Practical Examples:
```python
text = "My phone is 9876543210 and email is sakthi@gmail.com"

# Find phone number
phone = re.findall(r'\d{10}', text)
print(phone)  # ['9876543210']

# Find email
email = re.findall(r'\w+@\w+\.\w+', text)
print(email)  # ['sakthi@gmail.com']

# Mask digits
masked = re.sub(r'\d', 'X', text)
print(masked)
# "My phone is XXXXXXXXXX and email is sakthi@gmail.com"
```

### Email Validation:
```python
def is_valid_email(email):
    pattern = r'^[\w]+@[\w]+\.[a-z]{2,3}$'
    return bool(re.match(pattern, email))

print(is_valid_email("sakthi@gmail.com"))  # True
print(is_valid_email("invalid-email"))      # False
```

### Interview Answer:
"Regular expressions are patterns for string matching
and manipulation. re.findall returns all matches as list.
re.match checks pattern at string start. re.search finds
pattern anywhere. re.sub replaces matches. Used for
validation, data extraction and text processing."

## 3. LeetCode — Climbing Stairs (Dynamic Programming)

### Problem:
You can climb 1 or 2 steps at a time.
How many distinct ways to reach the top (n steps)?

```
n=1 → 1 way   → [1]
n=2 → 2 ways  → [1+1] or [2]
n=3 → 3 ways  → [1+1+1] or [1+2] or [2+1]
n=4 → 5 ways
n=5 → 8 ways
```

### Key Observation — Fibonacci!:
```
n=1 → 1
n=2 → 2
n=3 → 3
n=4 → 5
n=5 → 8
```
This IS the Fibonacci sequence!

### Why Fibonacci?:
```
To reach step n you can come from:
  Step n-1 → take 1 step
  Step n-2 → take 2 steps

ways(n) = ways(n-1) + ways(n-2)
```

### My First Attempt — Recursion (correct but slow):
```python
class Solution:
    def climbStairs(self, n):
        if n == 1:
            return 1
        if n == 2:
            return 2
        return self.climbStairs(n-1) + self.climbStairs(n-2)
```

### Why recursion is slow:
```
climbStairs(5)
├── climbStairs(4)
│   ├── climbStairs(3) ← calculated here
│   └── climbStairs(2)
└── climbStairs(3)     ← calculated AGAIN!
    ├── climbStairs(2)
    └── climbStairs(1)
```
Same values recalculated many times! O(2^n) — too slow!

### DP Solution — store previous results:
```python
class Solution:
    def climbStairs(self, n):
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        prev2 = 1  # ways to reach step 1
        prev1 = 2  # ways to reach step 2
        
        for i in range(3, n + 1):
            current = prev1 + prev2
            prev2 = prev1
            prev1 = current
        
        return prev1
```

**Time Complexity:** O(n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Dry Run:
```
n = 5
prev2=1, prev1=2

i=3: current=2+1=3, prev2=2, prev1=3
i=4: current=3+2=5, prev2=3, prev1=5
i=5: current=5+3=8, prev2=5, prev1=8

return 8 ✅
```

### Key insight of Dynamic Programming:
```
Recursion → correct but recalculates same values
DP        → stores previous results
           "Don't solve the same problem twice!"
```

### Recursion vs DP:
| | Recursion | Dynamic Programming |
|---|---|---|
| Logic | Same | Same |
| Efficiency | O(2^n) slow | O(n) fast |
| Memory | Call stack | Variables |
| Recalculation | Yes — many times | No — stored |

### Real world connection:
DP is used in:
- GPS shortest path finding
- Stock market predictions
- Game AI decision making
- Spell checkers

## Interview Questions and Answers

**Q: How do you reverse a string in Python?**
A: Using slicing with s[::-1]. The -1 step means
traverse from end to start. This works for any
sequence in Python — strings, lists, tuples.

**Q: What is the difference between re.match and re.search?**
A: re.match only checks at the beginning of the string.
re.search scans the entire string. If pattern is at
start — both work. If pattern is anywhere else —
only re.search finds it.

**Q: What is Dynamic Programming?**
A: Dynamic Programming solves complex problems by
breaking them into simpler subproblems and storing
results to avoid recalculation. Key principle: "Don't
solve the same problem twice." Used when problem has
overlapping subproblems. Climbing Stairs is classic DP
— ways(n) = ways(n-1) + ways(n-2), store previous
two values instead of recursing.

**Q: What is the difference between recursion and DP?**
A: Both use same logic. Recursion recalculates same
subproblems repeatedly — exponential time. DP stores
previous results — linear time. DP is essentially
optimized recursion with memoization.
