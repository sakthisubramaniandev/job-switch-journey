## 1. Linked Lists

### What is a Linked List?
A chain of nodes where each node contains:
- data → actual value
- next → pointer to next node

### Real life analogy:
```
Treasure hunt:
Clue 1 → "Go to library"
At library → Clue 2 → "Go to garden"
At garden  → Clue 3 → "Go to kitchen"
At kitchen → "FOUND TREASURE!"

Each clue has:
- The message (data)
- Where to go next (next pointer)
```

### Visual:
```
head
 ↓
[1 | →] ——→ [2 | →] ——→ [3 | →] ——→ [4 | →] ——→ [5 | None]
```

### Array vs Linked List:
```
Array — row of lockers (side by side):
[10] [20] [30] [40] [50]
 0    1    2    3    4
Can access any locker directly by index!

Linked List — chain:
[10|→]→[20|→]→[30|→]→[40|→]→[50|None]
Must go through each node to reach any node!
```

| | Array | Linked List |
|---|---|---|
| Access by index | O(1) fast | O(n) slow |
| Insert at start | O(n) slow | O(1) fast |
| Insert at end | O(1) fast | O(n) slow |
| Memory | Fixed | Dynamic |

### Node Structure:
```python
class Node:
    def __init__(self, data):
        self.data = data   # value in the box
        self.next = None   # arrow to next node
```

### Key concepts:
```
node.data → the VALUE stored in node
node.next → points to NEXT node (or None if last)
head      → first node — entry point to list
            lose head = lose entire list!
```

### Creating a Linked List:
```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


# Create nodes
n1 = Node(1)
n2 = Node(2)
n3 = Node(3)

# Connect them
n1.next = n2   # 1 points to 2
n2.next = n3   # 2 points to 3
               # 3 points to None

head = n1      # entry point

# Visual:
# [1|→]→[2|→]→[3|None]
```

### Traversing:
```python
def print_list(head):
    current = head

    while current:              # while not None
        print(current.data)
        current = current.next  # move to next node

# Step by step:
# current=n1 → print 1 → move to n2
# current=n2 → print 2 → move to n3
# current=n3 → print 3 → move to None
# current=None → stop!
```

### What current = current.next does:
Makes the NEXT node become the CURRENT node.
Like walking one step forward in the chain!

### Length of Linked List (written today):
```python
def length_of_linked_list(head):
    count = 0
    current_node = head

    while current_node is not None:
        count += 1
        current_node = current_node.next

    return count
```

### Common Operations:
```python
# Insert at beginning — O(1)
def insert_at_beginning(head, data):
    new_node = Node(data)
    new_node.next = head    # new node points to old head
    return new_node         # new node becomes head

# Insert at end — O(n)
def insert_at_end(head, data):
    new_node = Node(data)
    if not head:
        return new_node
    current = head
    while current.next:     # find last node
        current = current.next
    current.next = new_node
    return head

# Delete a node
def delete_node(head, target):
    if not head:
        return None
    if head.data == target:
        return head.next    # skip head!
    current = head
    while current.next:
        if current.next.data == target:
            current.next = current.next.next  # skip node!
            return head
        current = current.next
    return head
```

Browser history  → each page points to previous

## 2. LeetCode — Reverse Linked List (LC 206)

### Problem:
Given head of linked list, reverse it and return
new head.

```
Input:  1 → 2 → 3 → 4 → 5 → None
Output: 5 → 4 → 3 → 2 → 1 → None
```

### Why can't we start from end?:
```
In linked list you can ONLY go FORWARD!
Each node only knows its NEXT node.
No way to go backwards!
Must reverse arrows while traversing forward!
```

### Approach — Three Pointers:
```
prev      current    next_node
None   →    1     →   2 → 3 → 4 → 5 → None
```

At each step:
1. Save next node (before we lose it!)
2. Reverse the arrow
3. Move all pointers forward

### Visual step by step:
```
Original: 1 → 2 → 3 → None

Step 1: prev=None, current=1
  next_node = 2           (save next)
  1.next = None           (reverse arrow)
  prev = 1, current = 2   (move forward)

Step 2: prev=1, current=2
  next_node = 3           (save next)
  2.next = 1              (reverse arrow)
  prev = 2, current = 3   (move forward)

Step 3: prev=2, current=3
  next_node = None        (save next)
  3.next = 2              (reverse arrow)
  prev = 3, current = None (move forward)

current=None → stop!
return prev = 3 (new head!) ✅

Result: 3 → 2 → 1 → None ✅
```

### Solution:
```python
class Solution:
    def reverseList(self, head):
        prev = None
        current = head

        while current:
            next_node = current.next   # save next!
            current.next = prev        # reverse arrow
            prev = current             # move prev
            current = next_node        # move current

        return prev  # new head!
```

**Time Complexity:** O(n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Critical bug to remember:
```python
# WRONG!
current = current.next
# After current.next = prev
# current.next no longer points to next node!
# It points to prev!

# CORRECT!
next_node = current.next   # save BEFORE modifying!
current.next = prev        # now modify safely
current = next_node        # use saved value!
```

### Key lesson:
```
Always save next_node BEFORE modifying current.next!
Once you change current.next — original value is GONE!
```

### Dry Run:
```
1 → 2 → 3 → None
prev=None, current=1

Step 1:
  next_node=2, 1.next=None, prev=1, current=2
  None ← 1    2 → 3 → None

Step 2:
  next_node=3, 2.next=1, prev=2, current=3
  None ← 1 ← 2    3 → None

Step 3:
  next_node=None, 3.next=2, prev=3, current=None
  None ← 1 ← 2 ← 3

return prev=3 ✅
3 → 2 → 1 → None ✅
```

## Interview Questions and Answers

**Q: What is a Linked List?**
A: A linear data structure where each node has data
and a pointer to next node. Unlike arrays — not stored
contiguously. Head is entry point. Traversal O(n),
insertion at beginning O(1). Used for frequent
insertion/deletion at start.

**Q: What is the difference between Array and
Linked List?**
A: Array stores elements contiguously — O(1) index
access but O(n) insertion at start. Linked list stores
nodes anywhere in memory connected by pointers — O(n)
access but O(1) insertion at start. Array has fixed
size, linked list is dynamic.

**Q: How do you reverse a Linked List?**
A: Use three pointers — prev, current, next_node.
For each node: save next_node, reverse arrow to prev,
move prev and current forward. Critical: save next_node
BEFORE modifying current.next or you lose the reference.
Time O(n), space O(1).

**Q: Why must you save next_node before reversing?**
A: When you do current.next = prev, you overwrite the
pointer to the next node. If you haven't saved it —
you lose access to the rest of the list permanently.
Always save next_node = current.next first!
