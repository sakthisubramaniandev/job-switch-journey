## 1. Binary Trees

### What is a Binary Tree?
A hierarchical data structure where each node has
at most 2 children — left and right!

### Key Terms:
```
Root     → top node (entry point)
Parent   → node with children
Child    → node below parent
Leaf     → node with NO children
Height   → longest path root to leaf
Depth    → distance from root to node
```

### Visual:
```
        1          ← root
       / \
      2   3        ← children of 1
     / \
    4   5          ← leaves
```

### Tree Node Structure:
```python
class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None   # left child
        self.right = None  # right child
```

### Building a Tree:
```python
root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.left = TreeNode(4)
root.left.right = TreeNode(5)

#        1
#       / \
#      2   3
#     / \
#    4   5
```

### Why Trees?
```
Real world uses:
File system      → folders and files
Organization     → company hierarchy
Database indexes → B-trees for fast search
DOM              → HTML document structure
Decision making  → decision trees in ML
```

### Interview Answer:
"Binary tree is hierarchical structure where each
node has at most 2 children — left and right.
Root is top node, leaves have no children.
Height is longest root to leaf path.
Used for file systems, databases, DOM."

## 2. Tree Traversal

### What is Traversal?
Visiting every node in a specific order.
3 main types — all use recursion!

### Memory Trick:
```
PRE-order  → ROOT is FIRST  (pre = before everything)
IN-order   → ROOT is MIDDLE (in = in the middle)
POST-order → ROOT is LAST   (post = after everything)
```

### All traversals visit same 3 things:
```
Left subtree
Root (current node)
Right subtree
Only ORDER changes!
```

---

### 1. Inorder — Left, Root, Right:
```python
def inorder(root):
    if not root:
        return
    inorder(root.left)   # go left first
    print(root.val)      # visit root
    inorder(root.right)  # go right last
```

### Example:
```
        4
       / \
      2   6
     / \ / \
    1  3 5  7

Inorder: 1 → 2 → 3 → 4 → 5 → 6 → 7
```
Special property: Inorder of BST gives SORTED output!

---

### 2. Preorder — Root, Left, Right:
```python
def preorder(root):
    if not root:
        return
    print(root.val)       # visit root FIRST
    preorder(root.left)   # go left
    preorder(root.right)  # go right
```

### Example:
```
        4
       / \
      2   6
     / \ / \
    1  3 5  7

Preorder: 4 → 2 → 1 → 3 → 6 → 5 → 7
Key: fully explore LEFT subtree before RIGHT!
```

---

### 3. Postorder — Left, Right, Root:
```python
def postorder(root):
    if not root:
        return
    postorder(root.left)   # go left
    postorder(root.right)  # go right
    print(root.val)        # visit root LAST
```

### Example:
```
        4
       / \
      2   6
     / \ / \
    1  3 5  7

Postorder: 1 → 3 → 2 → 5 → 7 → 6 → 4
```

---

### Summary Table:
| Traversal | Order | Root position |
|---|---|---|
| Inorder | Left→Root→Right | Middle |
| Preorder | Root→Left→Right | First |
| Postorder | Left→Right→Root | Last |

### Practice results (verified today):
```
Tree:
        4
       / \
      2   6
     / \ / \
    1  3 5  7

Inorder:   1,2,3,4,5,6,7  ✅ (sorted!)
Preorder:  4,2,1,3,6,5,7  ✅ (root first!)
Postorder: 1,3,2,5,7,6,4  ✅ (root last!)
```

## 3. Tree Problem Template

### 90% of easy tree problems use this template:
```python
def solve(root):
    # Step 1 — base case
    if not root:
        return ???      # what to return for empty?

    # Step 2 — solve for children (recursion!)
    left = solve(root.left)
    right = solve(root.right)

    # Step 3 — combine and return
    return ??? (using left, right, root.val)
```

### How to approach tree problems:
```
Step 1 → Draw the tree on paper
Step 2 → Write base case first
Step 3 → Call function on left and right
Step 4 → Combine results and return
```

## 4. LeetCode — Maximum Depth of Binary Tree (LC 104)

### Problem:
Given root of binary tree return maximum depth.
Maximum depth = number of nodes along longest path
from root to farthest leaf.

```
        3
       / \
      9  20
        /  \
       15   7

Answer = 3
(3 → 20 → 15 or 3 → 20 → 7)
```

### Key insight:
```
depth(node) = 1 + max(depth(left), depth(right))

Every node counts itself as 1
Then picks the deeper child!
```

### Company hierarchy analogy:
```
CEO asks "how deep is my organization?"
Manager A → "just me → depth 1"
Manager B → "me + 1 level below → depth 2"
CEO → "1 + max(1,2) = 3" ✅
```

### Solution:
```python
class Solution:
    def maxDepth(self, root):
        # base case — empty tree = 0 depth
        if not root:
            return 0

        # solve for children
        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)

        # combine — count myself + deeper child
        return 1 + max(left_depth, right_depth)
```

**Time Complexity:** O(n) — visit every node
**Space Complexity:** O(h) — h is height of tree
**Result: ACCEPTED ✅**

### Full execution:
```
maxDepth(3):
  → maxDepth(9)
      → maxDepth(None) → 0
      → maxDepth(None) → 0
      → 1 + max(0,0) = 1

  → maxDepth(20)
      → maxDepth(15)
          → 1 + max(0,0) = 1
      → maxDepth(7)
          → 1 + max(0,0) = 1
      → 1 + max(1,1) = 2

  → 1 + max(1,2) = 3 ✅
```

### Why base case returns 0:
```python
if not root:
    return 0
# None node = nothing there = 0 depth
# Without this → crashes on leaf nodes!
```

### Key line breakdown:
```python
return 1 + max(left_depth, right_depth)
#       ↑         ↑
#   count ME   pick deeper side
```

## Interview Questions and Answers

**Q: What is a Binary Tree?**
A: Hierarchical data structure where each node has
at most 2 children — left and right. Root is top
node, leaves have no children. Used for file systems,
databases, DOM structure.

**Q: What are the three tree traversals?**
A: Inorder (Left→Root→Right), Preorder (Root→Left→Right),
Postorder (Left→Right→Root). All use recursion.
Inorder of BST gives sorted output. Memory trick:
Pre=root first, In=root middle, Post=root last.

**Q: How do you find maximum depth of binary tree?**
A: Recursively — base case returns 0 for None.
For each node return 1 + max(maxDepth(left),
maxDepth(right)). Every node counts itself as 1
and picks the deeper child. O(n) time.

**Q: Why use recursion for trees?**
A: Every subtree IS a tree — same structure repeats!
So same function works on every subtree naturally.
Base case handles None nodes. Recursive case
combines left and right results.
