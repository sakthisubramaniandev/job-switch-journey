## 1. Polymorphism

### What is Polymorphism?
Polymorphism means **same method name, different behaviour** 
depending on which class calls it.

Poly = Many
Morph = Forms
Polymorphism = Many Forms

### Real world analogy:
```
Animal    → make_sound()
Dog       → make_sound() → "Woof"
Cat       → make_sound() → "Meow"  
Cow       → make_sound() → "Moo"
```
Same method name — completely different behaviour!

### Difference between Polymorphism and Inheritance:
| Polymorphism | Inheritance |
|---|---|
| Same method name, different implementation | Child gets parent's exact implementation |
| Each class overrides the method differently | Child uses parent's method as is |
| About behaviour change | About code reuse |

### Code Example:
```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def make_sound(self):
        print("Some generic sound")


class Dog(Animal):
    def make_sound(self):           # overrides parent method
        print(f"{self.name} says: Woof!")


class Cat(Animal):
    def make_sound(self):           # overrides parent method
        print(f"{self.name} says: Meow!")


class Cow(Animal):
    def make_sound(self):           # overrides parent method
        print(f"{self.name} says: Moo!")


# Polymorphism in action!
animals = [Dog("Bruno"), Cat("Whiskers"), Cow("Bessie")]

for animal in animals:
    animal.make_sound()
# Same line — different behaviour each time!
```

### Output:
```
Bruno says: Woof!
Whiskers says: Meow!
Bessie says: Moo!
```

### Key Points:
- Child class **overrides** parent method with its own implementation
- Same method call behaves differently based on object type
- Python automatically calls the RIGHT version
- Used when different classes need same method but different logic

### Real world connection — PixelForge AI:
```python
class AIProvider:
    def generate(self, image): pass

    def generate(self, image):

        pass
```

## 2. Abstract Classes

### What is an Abstract Class?
A class that:
- **Cannot be instantiated directly** (no objects from it)
- **Forces all child classes** to implement specific methods
- Acts as a CONTRACT for child classes

### Problem without Abstract Class:
```python
s = Shape("Shape")
s.area()  # runs but does nothing — dangerous!
```
Someone could create a Shape object — but Shape has no real area!

### Solution — Abstract Class:
```python
from abc import ABC, abstractmethod
#        ↑ built-in Python module for abstract classes

class Shape(ABC):               # ABC = Abstract Base Class
    
    @abstractmethod             # forces child to implement
    def area(self):
        pass
    
    @abstractmethod
    def perimeter(self):
        pass


class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14 * self.radius * self.radius
    
    def perimeter(self):
        return 2 * 3.14 * self.radius


class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)


# This FAILS — cannot create abstract class directly
# s = Shape()  → TypeError!

# These work perfectly
c = Circle(5)
r = Rectangle(4, 6)

print(f"Circle area: {c.area()}")             # 78.5
print(f"Circle perimeter: {c.perimeter()}")    # 31.4
print(f"Rectangle area: {r.area()}")           # 24
print(f"Rectangle perimeter: {r.perimeter()}") # 20
```

### Key Points:
- Import `ABC` and `abstractmethod` from `abc` module
- `class Shape(ABC)` makes it abstract
- `@abstractmethod` forces child to implement
- If child doesn't implement → TypeError
- Cannot create object of abstract class directly

### Difference between Regular Class and Abstract Class:
| Regular Class | Abstract Class |
|---|---|
| Can create objects directly | Cannot create objects directly |
| Methods have full implementation | Abstract methods have no implementation |
| Child can choose to override | Child MUST override abstract methods |
| No contract enforced | Contract enforced strictly |

### Real world connection — Spring Boot:
JpaRepository in Spring Boot is essentially abstract!
It forces you to implement certain methods in your 
repository classes. Same concept in Java! 🔥

### Interview Answer:
"A regular class can be instantiated directly. An abstract 
class cannot — it's just a contract that forces all child 
classes to implement specific methods. Used when you want 
to define a common interface but leave implementation 
to subclasses."

## 3. First LeetCode Problem — Two Sum

### Problem:
Given an array of integers and a target number,
return indices of two numbers that add up to target.
```
Input:  nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
Because: nums[0] + nums[1] = 2 + 7 = 9
```

### Approach 1 — Brute Force:
Check every possible pair using two loops.
```python
def twoSum(nums, target):
    for i in range(len(nums)):
        for j in range(i+1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
```

**Problem:** Two loops = slow
**Time Complexity:** O(n²) — too slow for large arrays

### Approach 2 — HashMap (Optimal):
Key insight:
```
If current number is 2 and target is 9
Then complement = 9 - 2 = 7
We just need to find 7!
```
```python
def twoSum(nums, target):
    seen = {}                        # HashMap to store seen numbers
    
    for i, num in enumerate(nums):
        complement = target - num    # what number do we need?
        
        if complement in seen:       # have we seen it before?
            return [seen[complement], i]
        
        seen[num] = i                # store number and its index
    
    return []
```

**Time Complexity:** O(n) — fast! Only one loop
**Space Complexity:** O(n) — HashMap stores n elements

### Visual Dry Run:
```
nums = [2, 7, 11, 15], target = 9
seen = {}

Step 1: i=0, num=2
  complement = 9-2 = 7
  is 7 in seen? NO
  store → seen = {2:0}

Step 2: i=1, num=7
  complement = 9-7 = 2
  is 2 in seen? YES! ✅
  return [seen[2], 1] = [0, 1]
  DONE!
```

### Code Breakdown:
```python
seen = {}
# Empty HashMap — our cheat sheet

for i, num in enumerate(nums):
# enumerate gives BOTH index and value
# i=0,num=2 → i=1,num=7 → etc.

complement = target - num
# What number do we still need?

if complement in seen:
# Checking HashMap is O(1) — instant lookup!

return [seen[complement], i]
# seen[complement] gives stored index of complement

seen[num] = i
# Store current number → index for future lookups
```

### The HashMap Pattern:
```
1. Create empty HashMap
2. Loop through array
3. Calculate complement = target - current
4. Check if complement in HashMap
5. If YES → return the pair
6. If NO  → store current in HashMap
```

### Why HashMap is faster:
```
Brute Force → Check every pair
              1000 numbers = 1,000,000 checks ❌

HashMap     → Check each number once
              1000 numbers = 1,000 checks ✅

HashMap is like a cheat sheet:
Brute Force → Ask every person "Are you John?"
HashMap     → Write names on board as you meet them
              Need John? Just look at the board!
```

## Interview Questions and Answers

**Q: What is polymorphism?**
A: Polymorphism means same method name but different 
implementation based on which class calls it. It allows 
objects of different classes to be treated uniformly while 
behaving differently. Example: Animal.make_sound() behaves 
differently for Dog, Cat and Cow.

**Q: What is the difference between polymorphism and inheritance?**
A: Inheritance is about reusing code from parent class. 
Polymorphism is about same method having different behaviour 
in different classes. Inheritance shares implementation, 
polymorphism changes it.

**Q: Why can't you create an object of an abstract class?**
A: Abstract classes are incomplete by design — they have 
methods with no implementation. Creating an object would 
be meaningless since you can't call those methods. They 
exist only as contracts for child classes.

**Q: What does @abstractmethod do?**
A: It forces every child class to provide its own 
implementation of that method. If a child class doesn't 
implement it, Python throws a TypeError when you try 
to create an object of that child class.

**Q: What is the time complexity of Two Sum with HashMap?**
A: O(n) time and O(n) space. We iterate through the array 
once and each HashMap lookup is O(1), making the overall 
time complexity O(n). Much better than brute force O(n²).
