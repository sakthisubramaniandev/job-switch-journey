## 1. Classes and Objects

### What is a Class?
A class is a blueprint or template that defines:
- What data it holds (attributes)
- What it can do (methods)

### What is an Object?
An object is an actual instance created from a class.
One class can create many objects, each with their own data.

### Real world analogy:
- Class = Architectural plan of a house
- Object = The actual house built from that plan

### Syntax:
```python
class Developer:
    
    # Constructor — runs automatically when object is created
    def __init__(self, name, language):
        self.name = name          # self stores data inside object
        self.language = language
    
    # Method — what the object can do
    def introduce(self):
        print(f"Hi I am {self.name} and I code in {self.language}")

# Creating objects
dev1 = Developer("Sakthi", "Java")
dev2 = Developer("John", "Python")

dev1.introduce()  # Hi I am Sakthi and I code in Java
dev2.introduce()  # Hi I am John and I code in Python
```

### Key points:
- `class` keyword defines a class
- `__init__` is the constructor — runs when object is created
- `self` refers to the current object
- `self.name` stores data INSIDE that specific object
- Methods always have `self` as first parameter

## 2. Inheritance

### What is Inheritance?
One class (child) gets all properties and methods of another 
class (parent) automatically. Avoids code repetition.

### Real world analogy:
- Employee = parent class
- Manager = child class (IS an Employee + extra powers)
- Intern = child class (IS an Employee + extra powers)

### Syntax:
```python
class Employee:
    def __init__(self, name, company, salary):
        self.name = name
        self.company = company
        self.salary = salary
    
    def details(self):
        print(f"Name: {self.name}")
        print(f"Company: {self.company}")
        print(f"Salary: {self.salary}")


class Manager(Employee):        # Manager inherits Employee
    def __init__(self, name, company, salary, team_size):
        super().__init__(name, company, salary)  # calls parent init
        self.team_size = team_size               # adds new attribute
    
    def details(self):
        super().details()        # calls parent details()
        print(f"Team Size: {self.team_size}")    # adds extra info


class SeniorDeveloper(Employee):
    def __init__(self, name, company, salary, tech_stack):
        super().__init__(name, company, salary)
        self.tech_stack = tech_stack  # list of technologies
    
    def details(self):
        super().details()
        print(f"Tech Stack: {', '.join(self.tech_stack)}")


# Creating objects
manager = Manager("Sakthi", "Zoho", 500000, 10)
senior = SeniorDeveloper("John", "Freshworks", 800000, 
                          ["Python", "Java", "Spring Boot"])

manager.details()
senior.details()
```

### Key points:
- `class Child(Parent)` — child inherits parent
- `super()` refers to the parent class
- `super().__init__()` reuses parent's constructor
- `super().method()` reuses parent's method
- Child can ADD new attributes and methods
- Child can OVERRIDE parent methods

## 3. Dunder Methods (Magic Methods)

### What are Dunder Methods?
Special methods with double underscores (__) that Python 
calls automatically in certain situations.
Dunder = Double underscore

### Most important ones:
```python
class Employee:
    def __init__(self, name, company, salary):
        self.name = name
        self.company = company
        self.salary = salary
    
    # Called when you print(object)
    def __str__(self):
        return f"{self.name} works at {self.company}"
    
    # Called when you use len(object)
    def __len__(self):
        return len(self.name)
    
    # Called when you use ==
    def __eq__(self, other):
        return self.salary == other.salary
    
    # Called when you use >
    def __gt__(self, other):
        return self.salary > other.salary


emp1 = Employee("Sakthi", "Zoho", 500000)
emp2 = Employee("John", "Freshworks", 300000)

print(emp1)           # Sakthi works at Zoho
print(len(emp1))      # 6
print(emp1 == emp2)   # False
print(emp1 > emp2)    # True
```

### Key dunder methods to remember:
| Method | When called |
|---|---|
| `__init__` | Object created |
| `__str__` | print(object) |
| `__len__` | len(object) |
| `__eq__` | object == object |
| `__gt__` | object > object |
| `__dict__` | Access all attributes as dictionary |

### Interview answer:
"When you print an object Python automatically calls 
the __str__ method of that object."

## 4. Encapsulation

### What is Encapsulation?
Hiding internal data and controlling how it is accessed 
and modified. Protects data from accidental changes.

### How to make something private:
Use double underscore (__) before variable name.
```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.__salary = salary    # private — cannot access directly
    
    # Getter — controlled read access
    def get_salary(self):
        return self.__salary
    
    # Setter — controlled write access with validation
    def set_salary(self, new_salary):
        if new_salary > 0:
            self.__salary = new_salary
        else:
            print("Salary cannot be negative!")


emp = Employee("Sakthi", 500000)

# emp.__salary        → ERROR! Cannot access private variable
print(emp.get_salary())    # 500000 — works through getter
emp.set_salary(600000)     # updates through setter
emp.set_salary(-1000)      # Salary cannot be negative!
```

### Key points:
- `__variable` = private (double underscore)
- Getter method = controlled way to READ private data
- Setter method = controlled way to UPDATE private data
- Setter can validate data before updating
- Real world example: Your API key in .env is encapsulation!

## Questions and Answers

**Q: What is the difference between a class and an object?**
A: A class is a blueprint that defines attributes and behaviour. 
An object is a specific instance created from that blueprint. 
Multiple objects can be created from one class, each with their own data.

**Q: What does self mean in Python?**
A: self refers to the current instance of the class. 
It allows each object to store and access its own data separately.

**Q: What is super() used for?**
A: super() refers to the parent class. It allows child classes 
to call parent methods without repeating code — mainly used in 
__init__ to reuse parent's initialization logic.

**Q: What happens when you print an object?**
A: Python automatically calls the __str__ method of that object. 
Without __str__ defined, Python shows the default memory address.

**Q: What is encapsulation?**
A: Encapsulation is hiding internal data using private variables 
(double underscore) and controlling access through getter and 
setter methods. It protects data from accidental modification.
