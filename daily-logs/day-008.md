## 1. Two Pointer Pattern

### What is Two Pointer?
Instead of nested loops — use two pointers moving
towards each other or in same direction!

### Why Two Pointer?
```
Brute force → two loops → O(n²) slow
Two pointer → one loop  → O(n)  fast
```

### Visual:
```
Array = [1, 2, 3, 4, 5]
         ↑           ↑
        left        right

Move towards each other until they meet!
```

### Classic example — Palindrome check:
```python
def isPalindrome(arr):
    left = 0
    right = len(arr) - 1
    
    while left < right:
        if arr[left] != arr[right]:
            return False
        left += 1
        right -= 1
    
    return True

print(isPalindrome([1,2,3,2,1]))  # True
print(isPalindrome([1,2,3,4,5]))  # False
```

### Visual dry run:
```
[1, 2, 3, 2, 1]
 ↑           ↑   → 1==1 ✅ move inward
    ↑     ↑      → 2==2 ✅ move inward
       ↑         → left==right → stop!
Result: True ✅
```

### Two Sum with sorted array:
```python
def twoSumSorted(nums, target):
    left = 0
    right = len(nums) - 1
    
    while left < right:
        current_sum = nums[left] + nums[right]
        
        if current_sum == target:
            return [left, right]    # found!
        elif current_sum < target:
            left += 1               # need bigger
        else:
            right -= 1              # need smaller
    
    return []

print(twoSumSorted([1,2,3,4,6], 6))  # [1,3]
```

### Visual dry run:
```
[1, 2, 3, 4, 6], target=6
 ↑           ↑  → 1+6=7 > 6 → move right left
 ↑        ↑     → 1+4=5 < 6 → move left right
    ↑     ↑     → 2+4=6 == 6 → found! ✅
```

### When to use Two Pointer:
```
✅ Array or string is sorted
✅ Finding pairs with certain sum
✅ Palindrome checking
✅ Removing duplicates
✅ Reversing array/string
✅ Any time you need to compare
   elements from both ends
```

## 2. LeetCode — Palindrome Number

### Problem:
Given integer x, return true if x is a palindrome.
An integer is a palindrome when it reads the same
forward and backward.

```
121   → True  (reads same both ways)
-121  → False (negative numbers not palindrome)
10    → False (reads 01 backward)
```

### My Approach — Two Pointer on string:
```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        number = str(x)      # convert to string
        left = 0
        right = len(number) - 1

        while left < right:
            if number[left] != number[right]:
                return False
            left += 1
            right -= 1

        return True
```

**Time Complexity:** O(n)
**Space Complexity:** O(n) — string conversion
**Result: ACCEPTED ✅**

### Dry Run:
```
x = 121
number = "121"
left=0, right=2

Step 1: number[0]='1' == number[2]='1' ✅
        left=1, right=1

left == right → stop!
return True ✅

x = -121
number = "-121"
left=0, right=4

Step 1: number[0]='-' != number[4]='1' ❌
return False ✅
```

### Alternative — One liner:
```python
class Solution:
    def isPalindrome(self, x: int) -> bool:
        return str(x) == str(x)[::-1]
```

## Interview Questions and Answers

**Q: What is the Two Pointer technique?**
A: Two pointer uses two indices — usually left at
start and right at end — moving towards each other.
Reduces O(n²) brute force to O(n). Used for palindrome
checking, finding pairs with target sum, and problems
involving comparison of elements from both ends.

**Q: How do you check if a number is palindrome?**
A: Convert to string and use two pointer — compare
characters from both ends moving inward. If any
mismatch return False. If pointers meet — True.
Or use string slicing: str(x) == str(x)[::-1].

**Q: When would you use Two Pointer vs HashMap?**
A: Two pointer works best on sorted arrays or when
comparing elements from both ends. HashMap works
best for frequency counting or lookup problems.
Two pointer is O(1) space, HashMap is O(n) space.
