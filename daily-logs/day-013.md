## 1. Stack

### What is a Stack?
A data structure that follows LIFO principle.
Last In First Out — like a stack of plates!

### Real life analogy:
```
Stack of plates:
Push plate → goes on TOP
Pop plate  → taken from TOP

Last plate placed → first plate removed!
```

### Visual:
```
Push 1 → [1]
Push 2 → [1, 2]
Push 3 → [1, 2, 3]
Pop    → returns 3 → [1, 2]
Pop    → returns 2 → [1]
```

### Stack in Python:
```python
# Python list works as stack!
stack = []

# Push — add to top
stack.append(1)
stack.append(2)
stack.append(3)
print(stack)        # [1, 2, 3]

# Pop — remove from top
print(stack.pop())  # 3
print(stack.pop())  # 2
print(stack)        # [1]

# Peek — see top without removing
print(stack[-1])    # 1

# Check empty
print(len(stack) == 0)  # False
```

### Key operations:
| Operation | Method | Time |
|---|---|---|
| Push | append() | O(1) |
| Pop | pop() | O(1) |
| Peek | [-1] | O(1) |
| isEmpty | len()==0 | O(1) |

### Real world uses:
```
Browser back button  → stack of visited pages
Undo in text editor  → stack of actions
Function call stack  → Python uses internally!
Parentheses checking → common interview problem!
```

### Interview Answer:
"Stack is LIFO data structure — last element added
is first removed. In Python implemented using list
with append() for push and pop() for pop. Peek using
[-1]. Used for undo operations, browser history,
function calls, and bracket matching problems."

## 2. Queue

### What is a Queue?
A data structure that follows FIFO principle.
First In First Out — like a ticket counter queue!

### Real life analogy:
```
Queue at ticket counter:
Join at BACK
Leave from FRONT

First person in line → first person served!
```

### Visual:
```
Enqueue 1 → [1]
Enqueue 2 → [1, 2]
Enqueue 3 → [1, 2, 3]
Dequeue   → returns 1 → [2, 3]
Dequeue   → returns 2 → [3]
```

### Queue in Python:
```python
from collections import deque

queue = deque()

# Enqueue — add to back
queue.append(1)
queue.append(2)
queue.append(3)
print(queue)            # deque([1, 2, 3])

# Dequeue — remove from front
print(queue.popleft())  # 1
print(queue.popleft())  # 2
print(queue)            # deque([3])

# Peek front
print(queue[0])         # 3

# Check empty
print(len(queue) == 0)  # False
```

### Key operations:
| Operation | Method | Time |
|---|---|---|
| Enqueue | append() | O(1) |
| Dequeue | popleft() | O(1) |
| Peek | [0] | O(1) |
| isEmpty | len()==0 | O(1) |

### Real world uses:
```
Ticket counter     → first come first served
Printer queue      → documents printed in order
BFS traversal      → level by level tree/graph
CPU scheduling     → process management
```

### Interview Answer:
"Queue is FIFO data structure — first element added
is first removed. In Python implemented using
collections.deque with append() for enqueue and
popleft() for dequeue. Used for BFS, printer queues,
CPU scheduling. deque preferred over list because
list popleft() is O(n) while deque popleft() is O(1)."

## 3. Stack vs Queue:
| | Stack | Queue |
|---|---|---|
| Order | LIFO | FIFO |
| Add | append (top) | append (back) |
| Remove | pop (top) | popleft (front) |
| Real world | Undo/Back | Ticket counter |
| DSA use | Parentheses, DFS | BFS |

## 4. LeetCode — Valid Parentheses (LC 20)

### Problem:
Given string with brackets ()[]{}
Return true if brackets are valid.

```
"(())"   → True
"()[]{}" → True
"(]"     → False
"([)]"   → False
"({[]})" → True
```

### Rules:
```
Every opening bracket MUST be closed
Must be closed in CORRECT ORDER
```

### Why Stack is perfect:
```
Reading left to right:
Opening bracket → WRITE IT DOWN (push)
Closing bracket → CHECK last written (pop + compare)

Stack is LIFO → last written checked first!
Perfect for bracket matching!
```

### Mapping dictionary:
```python
mapping = {')': '(', ']': '[', '}': '{'}
# closing bracket → its matching opening bracket
# ) needs (
# ] needs [
# } needs {
```

### Solution:
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        mapping = {')': '(', ']': '[', '}': '{'}

        for char in s:
            if char in mapping:
                # closing bracket
                if not stack or stack[-1] != mapping[char]:
                    return False
                stack.pop()
            else:
                # opening bracket → push
                stack.append(char)

        return len(stack) == 0
```

**Time Complexity:** O(n)
**Space Complexity:** O(n)
**Result: ACCEPTED ✅**

### Two failure cases:
```python
if not stack or stack[-1] != mapping[char]:
    return False

# Failure 1 — stack empty:
s = ")"
stack = [] → nothing to match → invalid!

# Failure 2 — top doesn't match:
s = "(]"
stack = ['(']
mapping[']'] = '['
'(' != '[' → mismatch → invalid!
```

### Final check — why stack must be empty:
```python
return len(stack) == 0

# s = "((("
# stack = ['(', '(', '(']
# No closing brackets → unmatched!
# Stack not empty → False ✅
```

### Dry Run — valid case:
```
s = "({[]})"

'(' → push → stack=['(']
'{' → push → stack=['(', '{']
'[' → push → stack=['(', '{', '[']
']' → mapping[']']='[', top='[' ✅ pop → stack=['(', '{']
'}' → mapping['}']='{', top='{' ✅ pop → stack=['(']
')' → mapping[')']=''(', top='(' ✅ pop → stack=[]

len([])==0 → True ✅
```

### Dry Run — invalid case:
```
s = "([)]"

'(' → push → stack=['(']
'[' → push → stack=['(', '[']
')' → mapping[')']=''('
      top='[' != '(' ❌
      return False ✅
```

### Your understanding (in your own words!):
```
When we see closing bracket:
→ check top of stack for matching opening bracket
→ if stack empty → valid (no unmatched brackets)
→ if top matches → pop and continue
→ if top doesn't match → invalid!
```

## Interview Questions and Answers

**Q: What is the difference between Stack and Queue?**
A: Stack is LIFO — last element added is first removed.
Queue is FIFO — first element added is first removed.
Stack uses append/pop. Queue uses append/popleft.
Stack for undo/DFS. Queue for BFS/scheduling.

**Q: How do you implement Stack in Python?**
A: Using list — append() for push, pop() for pop,
[-1] for peek, len()==0 for isEmpty. All operations
are O(1).

**Q: How do you implement Queue in Python?**
A: Using collections.deque — append() for enqueue,
popleft() for dequeue. Don't use regular list because
list.pop(0) is O(n) while deque.popleft() is O(1).

**Q: How does Valid Parentheses work?**
A: Use stack. For opening brackets push to stack.
For closing brackets check if top of stack matches
corresponding opening bracket using mapping dictionary.
If mismatch or stack empty return False. At end stack
must be empty for valid string.

**Q: Why use Stack for bracket matching?**
A: Brackets must be closed in reverse order of opening.
Last opened must be first closed — exactly LIFO!
Stack naturally handles this with push/pop operations.
