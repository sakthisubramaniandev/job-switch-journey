## 1. Fast and Slow Pointer Pattern

### What is Fast and Slow Pointer?
Two pointers moving at different speeds!
```
slow → moves 1 step at a time
fast → moves 2 steps at a time
```

### Why it works:
```
Fast moves 2x speed of slow
When fast reaches end → slow is at middle!

Like two runners:
Runner A → 1 lap/min
Runner B → 2 laps/min
When B finishes 2 laps → A is at 1 lap (halfway!)
```

### Template:
```python
slow = head
fast = head

while fast and fast.next:
    slow = slow.next        # 1 step
    fast = fast.next.next   # 2 steps
```

### Why `while fast and fast.next`:
```python
fast        → check fast exists (not None)
fast.next   → check fast.next exists
              because fast.next.next would crash
              if fast.next is None!
```

## 2. Middle of Linked List (LC 876)

### Problem:
Given head of linked list return middle node.
If two middle nodes — return second middle.

```
1 → 2 → 3 → 4 → 5 → None  → return 3
1 → 2 → 3 → 4 → None      → return 3
```

### Visual dry run (odd length):
```
1 → 2 → 3 → 4 → 5 → None
slow=1, fast=1

Step 1: slow=2, fast=3
Step 2: slow=3, fast=5
Step 3: fast.next=None → stop!

Middle = slow = 3 ✅
```

### Visual dry run (even length):
```
1 → 2 → 3 → 4 → None
slow=1, fast=1

Step 1: slow=2, fast=3
Step 2: slow=3, fast=None → stop!

Middle = slow = 3 ✅ (second middle)
```

### Solution:
```python
class Solution:
    def middleNode(self, head):
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        return slow  # slow is at middle!
```

**Time Complexity:** O(n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Naive approach vs Fast/Slow:
```
Naive    → traverse twice → O(2n)
Fast/Slow → traverse once → O(n) ✅
```

## 3. Linked List Cycle (LC 141) — Floyd's Algorithm

### Problem:
Given head of linked list, return true if cycle exists.

### What is a cycle?:
```
Normal list:
1 → 2 → 3 → 4 → 5 → None

List with cycle:
1 → 2 → 3 → 4 → 5
            ↑       ↓
            └───────┘
Node 5 points back to node 3!
Goes forever — never reaches None!
```

### How to detect — Fast and Slow!:
```
No cycle  → fast reaches None
Cycle     → fast eventually catches slow!
            They MEET inside the cycle!
```

### Race track analogy:
```
Straight road  → fast reaches end, never meets slow
Circular track → fast laps slow → they MUST meet!
```

### Visual:
```
1 → 2 → 3 → 4 → 5
            ↑       ↓
            └───────┘

slow=1, fast=1

Step 1: slow=2, fast=3
Step 2: slow=3, fast=5
Step 3: slow=4, fast=4 ← MET! Cycle! ✅
```

### Solution:
```python
class Solution:
    def hasCycle(self, head):
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:    # they met!
                return True     # cycle exists!

        return False            # no cycle
```

**Time Complexity:** O(n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Key difference — Middle vs Cycle:
```
Middle → return slow AFTER loop ends
Cycle  → check slow == fast DURING loop
```

## Fast/Slow Pointer — Two use cases:
```
Use case 1 → Finding middle
             return slow when loop ends

Use case 2 → Detecting cycle
             check if slow == fast during loop
             if they meet → cycle exists!
```

## Interview Questions and Answers

**Q: How do you find the middle of a linked list?**
A: Use fast and slow pointers. Both start at head.
Slow moves 1 step, fast moves 2 steps. When fast
reaches end — slow is at middle. O(n) time, O(1)
space. Better than naive two-pass O(2n) approach.

**Q: How do you detect a cycle in a linked list?**
A: Floyd's cycle detection — fast and slow pointers.
Both start at head. Slow moves 1 step, fast 2 steps.
If cycle exists — fast eventually catches slow and
they meet. If no cycle — fast reaches None. O(n)
time, O(1) space.

**Q: What is Floyd's Algorithm?**
A: Also called tortoise and hare algorithm. Uses two
pointers at different speeds to detect cycles in
linked list. Slow pointer moves 1 step, fast moves 2.
On circular path they must eventually meet. Named
after Robert Floyd who invented it.

**Q: What is the difference between finding middle
and cycle detection using fast/slow pointers?**
A: Same pointer setup but different check. For middle
— return slow when loop ends. For cycle — check if
slow equals fast DURING the loop. If they meet —
cycle exists.
