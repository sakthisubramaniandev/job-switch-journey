## 1. Sliding Window Pattern

### What is Sliding Window?
Instead of recalculating everything from scratch —
slide a fixed size window across the array!
Add new element on right, remove old element on left.

### Why Sliding Window?
```
Brute force    → O(n*k) — recalculates every window
Sliding window → O(n)   — just add and subtract!
```

### Visual:
```
Array = [1, 3, 2, 6, 4, 8, 7, 5], k=3

Window 1: [1, 3, 2] sum=6
Window 2:    [3, 2, 6] sum=6-1+6=11
Window 3:       [2, 6, 4] sum=11-3+4=12
Window 4:          [6, 4, 8] sum=12-2+8=18
Window 5:             [4, 8, 7] sum=18-6+7=19
Window 6:                [8, 7, 5] sum=19-4+5=20
```

### How sliding works:
```
Remove leftmost element → arr[i - k]
Add new rightmost element → arr[i]
window_sum = window_sum + arr[i] - arr[i-k]
```

### Code Template:
```python
def sliding_window(arr, k):
    # Step 1 — calculate first window
    window_sum = sum(arr[:k])
    max_sum = window_sum

    # Step 2 — slide the window
    for i in range(k, len(arr)):
        window_sum += arr[i]        # add new element
        window_sum -= arr[i - k]    # remove old element
        max_sum = max(max_sum, window_sum)

    return max_sum
```

### Brute Force vs Sliding Window:
```python
# Brute force — O(n*k) slow!
def maxSum_brute(arr, k):
    max_sum = 0
    for i in range(len(arr) - k + 1):
        window_sum = sum(arr[i:i+k])  # recalculates!
        max_sum = max(max_sum, window_sum)
    return max_sum

# Sliding window — O(n) fast!
def maxSum_sliding(arr, k):
    window_sum = sum(arr[:k])
    max_sum = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i-k]
        max_sum = max(max_sum, window_sum)
    return max_sum
```

### Minimum Sum Practice (written today):
```python
def slidingWindow(arr, k):
    window_sum = sum(arr[:k])
    min_sum = window_sum

    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i - k]
        min_sum = min(min_sum, window_sum)

    return min_sum

arr = [3, 1, 4, 1, 5, 9, 2, 6]

```

```
✅ Longest substring with condition
✅ Any time tracking window of elements

```

## 2. LeetCode — Maximum Average Subarray I

### Problem:
Given array and integer k, find contiguous subarray
of length k with maximum average value. Return average.

```
Input:  nums=[1,12,-5,-6,50,3], k=4
Output: 12.75
Reason: [12,-5,-6,50] = 51/4 = 12.75
```

### My Solution — Sliding Window:
```python
class Solution:
    def findMaxAverage(self, nums, k):
        window_sum = sum(nums[:k])
        max_sum = window_sum

        for i in range(k, len(nums)):
            window_sum += nums[i] - nums[i-k]
            max_sum = max(max_sum, window_sum)

        return max_sum / k  # divide once at end!
```

**Time Complexity:** O(n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Key insight:
```
Track maximum SUM not average during loop
Divide by k ONCE at the end
Avoids unnecessary division every iteration!
```

### Dry Run:
```

First window: sum([1,12,-5,-6]) = 2
max_sum = 2

i=4: window_sum = 2 + 50 - 1 = 51
     max_sum = max(2, 51) = 51

i=5: window_sum = 51 + 3 - 12 = 42
     max_sum = max(51, 42) = 51

return 51/4 = 12.75 ✅
```

## Interview Questions and Answers

**Q: What is the Sliding Window pattern?**
A: Sliding window maintains a window over array by
adding new right element and removing old left element
instead of recalculating. Reduces O(n*k) to O(n).
Key line: window_sum += arr[i] - arr[i-k].

**Q: When would you use Sliding Window vs Two Pointer?**
A: Sliding window is used when working with a fixed
or variable size subarray/substring — tracking sum,
average, or condition within window. Two pointer is
used when comparing elements from both ends or finding
pairs. Both are O(n) but solve different problems.

**Q: What is the difference between Sliding Window
and Kadane's Algorithm?**
A: Both track running sums but differently. Sliding
window uses fixed size k — add right, remove left.
Kadane's uses variable size — decides whether to
extend or start fresh at each step. Sliding window
for fixed k problems, Kadane's for maximum subarray.
