## 1. Decorators

### What is a Decorator?
A decorator is a function that:
- Takes another function as input
- Adds extra behaviour around it
- Returns a modified version
- Does NOT modify the original function

### One line definition:
`func = decorator(func)` — shorthand is `@decorator`

### Problem decorators solve:
Without decorators — repeating same code in every function:
```python
def add(a, b):
    print("Starting...")  # repeated!
    result = a + b
    print("Done!")        # repeated!
    return result

def multiply(a, b):
    print("Starting...")  # repeated!
    result = a * b
    print("Done!")        # repeated!
    return result
```

With decorators — write once, apply everywhere:
```python
@logger
def add(a, b):
    return a + b

@logger
def multiply(a, b):
    return a * b
```

### Decorator Structure:
```python
def decorator_name(func):      # takes function as input
    def wrapper(*args, **kwargs):
        # code BEFORE original function
        result = func(*args, **kwargs)  # calls original
        # code AFTER original function
        return result
    return wrapper              # returns modified function
```

### Logger Decorator (written today):
```python
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"Function {func.__name__} is starting...")
        result = func(*args, **kwargs)
        print(f"Function {func.__name__} is done!!")
        return result
    return wrapper


@logger
def sub(a, b):
    return a - b

@logger
def mul(a, b):
    return a * b


result1 = sub(10, 3)
print(f"Result: {result1}")

result2 = mul(4, 5)
print(f"Result: {result2}")
```

### Output:
```
Function sub is starting...
Function sub is done!!
Result: 7
Function mul is starting...
Function mul is done!!
Result: 20
```

### Timer Decorator:
```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} took {end-start:.4f} seconds")
        return result
    return wrapper


@timer
def add(a, b):
    return a + b

add(5, 3)  # add took 0.0001 seconds
```

### Login Check Decorator:
```python
def require_login(func):
    def wrapper(*args, **kwargs):
        is_logged_in = True

        if not is_logged_in:
            print("Please login first!")
            return

        return func(*args, **kwargs)
    return wrapper


@require_login
def view_dashboard():
    print("Welcome to dashboard!")

view_dashboard()  # Welcome to dashboard!
```

### Internal Working — Step by Step:
```
1. Python sees @logger above add function
2. Python translates to: add = logger(add)
3. logger receives original add function
4. logger creates wrapper function inside
5. logger returns wrapper
6. Now add points to wrapper, not original!
7. When add(5,3) is called → wrapper(5,3) runs
8. wrapper prints "starting..."
9. wrapper calls original func(5,3)
10. original add runs → returns 8
11. wrapper prints "done!"
12. wrapper returns 8
```

### Key concepts:
- `*args` → captures any positional arguments
- `**kwargs` → captures any keyword arguments
- `func.__name__` → gives original function name as string
- `@decorator` = shorthand for `func = decorator(func)`

### Real world connection:
```python
# FastAPI uses decorators!
@app.get("/")           # ← decorator registering endpoint
def home():
    return {"status": "running"}

@app.post("/generate")  # ← decorator registering endpoint
def generate():
    pass
```

Now you know exactly what FastAPI does behind the scenes! 🔥

### Interview Answer:
"A decorator is a function that takes another function as 
input, adds extra behaviour around it without modifying 
the original function, and returns a modified version. 
It uses @symbol as shorthand for func = decorator(func). 
Used for logging, timing, authentication. In FastAPI, 
@app.get() and @app.post() are decorators."

## 2. Generators

### What is a Generator?
A function that produces values ONE AT A TIME instead of 
all at once. Uses `yield` instead of `return`.

### Problem generators solve:
```python
# Bad — stores 1 million numbers in RAM!
def get_numbers():
    numbers = []
    for i in range(1, 1000001):
        numbers.append(i)
    return numbers  # all in memory at once!

# Good — produces one number at a time!
def get_numbers():
    for i in range(1, 1000001):
        yield i     # one at a time, almost zero memory!
```

### yield vs return:
```python
# return → gives value and STOPS function completely
def normal():
    return 1
    return 2    # never reaches here!

# yield → gives value and PAUSES function
# resumes from same point when called again!
def generator():
    yield 1     # pause here
    yield 2     # resume here next time
    yield 3     # resume here after that
```

### How to use a Generator:
```python
def my_generator():
    yield 1
    yield 2
    yield 3

gen = my_generator()  # creates generator object

print(next(gen))  # 1 — gets next value
print(next(gen))  # 2
print(next(gen))  # 3
print(next(gen))  # StopIteration error — nothing left!

# Or use in for loop
for val in my_generator():
    print(val)
```

### Even Numbers Generator (written today):
```python
def even_numbers():
    a = 0
    while True:       # infinite generator!
        yield a
        a += 2


even_no = even_numbers()

for _ in range(5):
    print(next(even_no))
```

### Output:
```
0
2
4
6
8
```

### Fibonacci Generator:
```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b


fib = fibonacci()

for _ in range(8):
    print(next(fib))
# Output: 0 1 1 2 3 5 8 13
```

### Visual mental model:
```
Normal function:
Start → Run everything → Return result → END

Generator function:
Start → yield 1 → PAUSE
Resume → yield 2 → PAUSE
Resume → yield 3 → PAUSE
Resume → StopIteration
```

### Key Differences:
| Normal Function | Generator |
|---|---|
| Uses return | Uses yield |
| Returns all at once | Returns one at a time |
| Stores everything in memory | Almost zero memory |
| Runs completely | Pauses and resumes |
| Returns a value | Returns generator object |

### Real world connection:
```python
# Reading huge files efficiently
def read_file(filename):
    with open(filename) as f:
        for line in f:
            yield line   # one line at a time!
```

### Interview Answer:
"A generator is a function that uses yield instead of 
return to produce values one at a time. It pauses after 
each yield and resumes when next() is called. It uses 
almost zero memory compared to storing everything at once. 
Used for large datasets, infinite sequences, file reading."

## 3. LeetCode — Valid Anagram

### Problem:
Given two strings s and t, return true if t is an anagram 
of s, and false otherwise.
```
Input:  s = "anagram", t = "nagaram"
Output: true

Input:  s = "rat", t = "car"
Output: false
```

### What is an Anagram?
Two strings are anagrams if:
- They have the same length
- They use exactly the same letters
- Placement can be different

Example: "car" and "rac" → same letters, different order ✅

### My Instinct (correct!):
```
1. Check if both strings have equal length
2. Split letter by letter
3. Sort by ASCII value
4. Compare sorted strings
5. If equal → valid anagram
```

### Approach 1 — Sort (submitted today):
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        # Step 1 — check length
        if len(s) != len(t):
            return False
        
        # Step 2 — sort both and compare
        return sorted(s) == sorted(t)
```

**Time Complexity:** O(n log n) — sorting takes n log n
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Dry Run:
```
s = "anagram", t = "nagaram"

len(s) = 7 == len(t) = 7 ✅

sorted("anagram") = ['a','a','a','g','m','n','r']
sorted("nagaram") = ['a','a','a','g','m','n','r']

Equal? YES → return True ✅
```

### Approach 2 — HashMap (faster):
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        
        count = {}
        
        # Count characters in s
        for char in s:
            count[char] = count.get(char, 0) + 1
        
        # Subtract characters in t
        for char in t:
            if char not in count:
                return False
            count[char] -= 1
            if count[char] < 0:
                return False
        
        return True
```

**Time Complexity:** O(n) — faster!
**Space Complexity:** O(n) — HashMap storage

### HashMap Dry Run:
```
s = "car", t = "rac"

Count s:
c → {c:1}
a → {c:1, a:1}
r → {c:1, a:1, r:1}

Check t:
r → count[r] = 1-1 = 0 ✅
a → count[a] = 1-1 = 0 ✅
c → count[c] = 1-1 = 0 ✅

All good → return True ✅
```

### Comparison:
| Approach | Time | Space | Notes |
|---|---|---|---|
| Sort | O(n log n) | O(1) | Simple, clean |
| HashMap | O(n) | O(n) | Faster, more complex |

### Interview tip:
Start with sort approach (simpler to explain).
Then say "We can optimize to O(n) using HashMap."
That shows you think about optimization! 💡

## Interview Questions and Answers

**Q: What is a decorator in Python?**
A: A decorator is a function that takes another function 
as input, adds extra behaviour without modifying original, 
and returns modified version. @symbol is shorthand for 
func = decorator(func). Used for logging, timing, auth.

**Q: What is the difference between yield and return?**
A: return gives a value and stops the function completely. 
yield gives a value and pauses the function — it resumes 
from the same point when next() is called again. yield 
is used in generators to produce values one at a time.

**Q: When would you use a generator over a normal function?**
A: When dealing with large datasets or infinite sequences 
where storing everything in memory at once would be 
wasteful or impossible. Generators produce values on 
demand using almost zero memory.

**Q: What is an anagram?**
A: Two strings are anagrams if they contain exactly the 
same characters with the same frequency, regardless of 
order. Example: "listen" and "silent" are anagrams.
