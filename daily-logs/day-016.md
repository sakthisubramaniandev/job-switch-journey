## 1. Same Tree (LC 100)

### Problem:
Given roots of two binary trees p and q,
return true if they are the same tree.
Same means: same structure AND same values.

```
Same ✅:
    1       1
   / \     / \
  2   3   2   3

Not Same ❌:
    1       1
   /         \
  2           2
```

### Approach:
```
Compare node by node recursively!

Base case 1 → both None → True (both empty = same!)
Base case 2 → one None  → False (different structure!)
Base case 3 → values differ → False

Recursive → check left subtrees AND right subtrees
```

### Solution:
```python
class Solution:
    def isSameTree(self, p, q):
        # both None → same!
        if not p and not q:
            return True

        # one None → different!
        if not p or not q:
            return False

        # values differ → different!
        if p.val != q.val:
            return False

        # check both subtrees
        return self.isSameTree(p.left, q.left) and \
               self.isSameTree(p.right, q.right)
```

**Time Complexity:** O(n)
**Space Complexity:** O(h)
**Result: ACCEPTED ✅**

### Dry Run:
```
p:  1      q:  1
   / \        / \
  2   3      2   3

isSameTree(1,1):
  1==1 ✅
  → isSameTree(2,2):
      2==2 ✅
      → isSameTree(None,None) → True
      → isSameTree(None,None) → True
      → True
  → isSameTree(3,3):
      3==3 ✅
      → True
  → True and True → True ✅
```

### Key insight:
```
AND condition is crucial!
return left_same AND right_same
Both must be same for tree to be same!
```

### Interview Answer:
"Compare trees recursively node by node. Base cases:
both None returns True (same empty trees), one None
returns False (different structure), values differ
returns False. Recursive case checks left subtrees
AND right subtrees both match. O(n) time."

## 2. Symmetric Tree (LC 101)

### Problem:
Given root of binary tree check if it is
a mirror of itself (symmetric around center).

```
Symmetric ✅:
        1
       / \
      2   2
     / \ / \
    3  4 4  3

Not Symmetric ❌:
        1
       / \
      2   2
       \   \
        3   3
```

### Key insight — Mirror comparison:
```
NOT checking if left == left
CHECKING if left mirrors right!

left.left  must equal right.right
left.right must equal right.left

Like folding tree in half —
left side must match right side!
```

### Visual mirror check:
```
        1
       / \
      2   2
     / \ / \
    3  4 4  3

isMirror(2, 2):
  2==2 ✅
  isMirror(3, 3) ← left.left vs right.right ✅
  isMirror(4, 4) ← left.right vs right.left ✅
```

### Solution:
```python
class Solution:
    def isSymmetric(self, root):
        def isMirror(left, right):
            # both None → symmetric!
            if not left and not right:
                return True

            # one None → not symmetric!
            if not left or not right:
                return False

            # values must match AND
            # left.left mirrors right.right AND
            # left.right mirrors right.left
            return (left.val == right.val) and \
                   isMirror(left.left, right.right) and \
                   isMirror(left.right, right.left)

        return isMirror(root.left, root.right)
```

**Time Complexity:** O(n)
**Space Complexity:** O(h)
**Result: ACCEPTED ✅**

### Dry Run:
```
        1
       / \
      2   2
     / \ / \
    3  4 4  3

isMirror(2, 2):
  2==2 ✅
  isMirror(3, 3):  ← left.left vs right.right
    3==3 ✅
    isMirror(None,None) → True
    isMirror(None,None) → True
    → True
  isMirror(4, 4):  ← left.right vs right.left
    4==4 ✅
    → True
  → True ✅
```

### Same Tree vs Symmetric Tree:
```
Same Tree   → compare p.left with q.left
              compare p.right with q.right
              (same side comparison)

Symmetric   → compare left.left with right.right
              compare left.right with right.left
              (cross side comparison — mirror!)
```

### Interview Answer:
"Check symmetry using helper isMirror(left, right).
Base cases: both None True, one None False.
Key insight: left.left must mirror right.right AND
left.right must mirror right.left — cross comparison!
Call isMirror(root.left, root.right). O(n) time."

## Interview Questions and Answers

**Q: How do you check if two trees are the same?**
A: Recursively compare node by node. Both None returns
True, one None returns False, values differ returns
False. Recursive case checks left subtrees AND right
subtrees both match. O(n) time O(h) space.

**Q: How do you check if a tree is symmetric?**
A: Use helper isMirror(left, right). Both None True,
one None False. Key: left.left must mirror right.right
AND left.right must mirror right.left — cross comparison.
Call isMirror(root.left, root.right). O(n) time.

**Q: What is the difference between Same Tree
and Symmetric Tree?**
A: Same Tree compares same sides — left with left,
right with right. Symmetric compares mirror sides —
left.left with right.right, left.right with right.left.
Both use same base cases and recursive structure.

**Q: When should nested functions use self?**
A: Never! self is only for class methods defined
directly in the class. Nested functions defined inside
another method are called directly without self.
Using self.nested_func causes AttributeError.
