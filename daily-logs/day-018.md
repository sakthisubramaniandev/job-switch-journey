## 1. Merge Two Sorted Lists (LC 21)

### Problem:
Merge two sorted linked lists into one sorted list.

```
List1: 1 → 3 → 5 → None
List2: 2 → 4 → 6 → None

Merged: 1 → 2 → 3 → 4 → 5 → 6 → None
```

### Real world analogy:
```
Merging two sorted decks of playing cards!
Pick smaller card from either deck
Add to result deck
Repeat until both decks empty!
```

### Approach — Two Pointers + Dummy Node:
```
p1 → current node in List1
p2 → current node in List2

Compare p1.val and p2.val
Pick smaller → add to result
Move that pointer forward
Repeat!
```

### Visual step by step:
```
List1: 1 → 3 → 5
List2: 2 → 4 → 6

p1=1, p2=2 → 1<2 → pick 1, move p1
p1=3, p2=2 → 3>2 → pick 2, move p2
p1=3, p2=4 → 3<4 → pick 3, move p1
p1=5, p2=4 → 5>4 → pick 4, move p2
p1=5, p2=6 → 5<6 → pick 5, move p1
p1=None    → attach rest of List2 (6)

Result: 1→2→3→4→5→6 ✅
```

### Dummy Node trick:
```python
dummy = ListNode(0)
current = dummy

# After building:
# dummy → 1 → 2 → 3 → 4 → 5 → 6
#   ↑
#   skip this, return dummy.next!
```

Why dummy?
```
Without dummy → need special case for first node
With dummy    → treat ALL nodes the same way!
Much cleaner code!
```

### Solution:
```python
class Solution:
    def mergeTwoLists(self, list1, list2):
        dummy = ListNode(0)   # dummy head node
        current = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                current.next = list1    # assign NODE not value!
                list1 = list1.next      # move list1 forward!
            else:
                current.next = list2    # assign NODE not value!
                list2 = list2.next      # move list2 forward!

            current = current.next      # move current forward

        # attach remaining nodes (one list might have more)
        current.next = list1 or list2

        return dummy.next  # skip dummy, return real head!
```

**Time Complexity:** O(n+m)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Common mistakes made today:
```python
# WRONG — assigning value not node!
current.next = list1.val   ❌

# CORRECT — assign whole node!
current.next = list1       ✅

# WRONG — moving pointer incorrectly!
list1 = current.next       ❌

# CORRECT — move to next in list1!
list1 = list1.next         ✅

# WRONG — inside loop!
while ...:
    current.next = list1 or list2  ❌

# CORRECT — outside loop!
while ...:
    ...
current.next = list1 or list2      ✅
```

### Why `current.next = list1 or list2`:
```
When loop ends — one list is exhausted
Other list might have remaining nodes
list1 or list2 → returns whichever is not None
Attach remaining nodes in one line!
```

### Interview Answer:
"Use dummy head node and two pointers. Compare
current nodes of both lists, pick smaller and
advance that pointer. Move current forward each
step. After loop attach remaining nodes with
list1 or list2. Return dummy.next. O(n+m) time
O(1) space. Dummy node eliminates edge cases."

## 2. Intersection of Two Linked Lists (LC 160)

### Problem:
Find node where two linked lists intersect.
Intersection means SAME NODE in memory — not just
same value!

```
List A: 4 → 1 → 8 → 4 → 5
List B:      5 → 6 → 8 → 4 → 5
                     ↑
              intersection at node 8!
              (same memory address!)
```

### Key insight — not value, but node:
```
Node 8 in List A and List B
are THE SAME NODE — same memory address!
Not just nodes with value 8!
```

### Approach — Redirect Pointers Trick:
```
When p1 reaches end → redirect to headB
When p2 reaches end → redirect to headA

Both travel same total distance:
len(A) + len(B)

They MUST meet at intersection!
If no intersection → both reach None together!
```

### Visual:
```
A: 4→1→8→4→5→[B]→5→6→8...
B: 5→6→8→4→5→[A]→4→1→8...
                        ↑
                   meet here! (node 8)
```

### Why this works:
```
List A length = 5, List B length = 4
Intersection at node 8 (3rd from end)

p1 travels: A(5) + B(1,2) = 7 steps to reach 8
p2 travels: B(4) + A(1,2,3) = 7 steps to reach 8

Same distance → meet at intersection! ✅

No intersection:
p1 travels: len(A) + len(B)
p2 travels: len(B) + len(A)
Both reach None → p1 == p2 == None → return None ✅
```

### Solution:
```python
class Solution:
    def getIntersectionNode(self, headA, headB):
        p1 = headA
        p2 = headB

        while p1 != p2:
            p1 = p1.next if p1 else headB  # redirect to headB!
            p2 = p2.next if p2 else headA  # redirect to headA!

        return p1  # intersection node or None!
```

**Time Complexity:** O(n+m)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Dry Run:
```
A: 4→1→8→4→5
B: 5→6→8→4→5 (8 is intersection)

p1=4, p2=5 → not equal → advance
p1=1, p2=6 → not equal → advance
p1=8, p2=8 → equal! → return node(8) ✅

Wait — lengths different so redirect happens:
p1 travels A then redirects to B
p2 travels B then redirects to A
After redirect they're in sync and meet at 8!
```

### Elegant trick summary:
```
p1 = p1.next if p1 else headB
#    ↑ advance    ↑ redirect when exhausted

This one line handles:
1. Normal traversal
2. Redirection at end
3. No intersection case (both become None)
```

### Interview Answer:
"Use two pointers starting at each head. When
pointer reaches end redirect to other list's head.
Both travel len(A)+len(B) total distance so they
meet at intersection. If no intersection both
become None simultaneously and loop exits. O(n+m)
time O(1) space — elegant one-line trick per pointer."

## Interview Questions and Answers

**Q: How do you merge two sorted linked lists?**
A: Use dummy head node and two pointers. Compare
current nodes, pick smaller and advance that pointer.
Move result pointer forward each step. After loop
attach remaining with list1 or list2. Return
dummy.next. O(n+m) time, O(1) space.

**Q: What is the dummy node trick?**
A: Create a dummy ListNode(0) as fake head. Build
result list from dummy.next. Eliminates special case
handling for first node — all nodes treated uniformly.
Return dummy.next at end to skip dummy node.

**Q: How do you find intersection of two linked lists?**
A: Use two pointers. When p1 exhausts list A redirect
to headB. When p2 exhausts list B redirect to headA.
Both travel len(A)+len(B) total — meet at intersection.
If no intersection both become None. O(n+m) time O(1)
space. Elegant one-line trick per pointer.

**Q: Why does the redirect trick work?**
A: Both pointers travel same total distance len(A)+len(B).
After redirect they're perfectly synchronized —
offset difference eliminated. They must meet at
intersection node or both become None simultaneously
if no intersection exists.
