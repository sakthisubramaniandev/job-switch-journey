## 1. Binary Search Pattern

### What is Binary Search?
Instead of checking every element — cut search space
in HALF every step!

### Why Binary Search?
```
Linear Search  → check every element → O(n)
Binary Search  → cut in half each time → O(log n)
```

### IMPORTANT — Only works on SORTED arrays!

### Real life analogy:
```
Finding "Zebra" in dictionary:
Linear → check every word from A → 10,000 checks!
Binary → open middle → "Monkey"
         "Zebra" after "Monkey" → ignore first half!
         Keep cutting in half → find in ~13 steps!
```

### Visual:
```
arr = [1, 3, 5, 7, 9, 11, 13, 15], target=7

left=0, right=7
mid=3 → arr[3]=7 == 7 → FOUND! ✅

target=11:
left=0, right=7
mid=3 → arr[3]=7 < 11 → search RIGHT
left=4, right=7
mid=5 → arr[5]=11 == 11 → FOUND! ✅
```

### Code Template:
```python
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid           # found!
        elif arr[mid] < target:
            left = mid + 1       # search right half
        else:
            right = mid - 1      # search left half

    return -1                    # not found


arr = [1, 3, 5, 7, 9, 11, 13, 15]
print(binary_search(arr, 7))    # 3
print(binary_search(arr, 11))   # 5
print(binary_search(arr, 4))    # -1
```

### Breaking down key parts:
```python
mid = (left + right) // 2
# find middle index
# // is integer division — no decimals

arr[mid] == target → return mid    # found!
arr[mid] < target  → left = mid+1  # go RIGHT
arr[mid] > target  → right = mid-1 # go LEFT
```

### Why O(log n)?:
```
16 elements:
Step 1 → 16 elements
Step 2 → 8 elements
Step 3 → 4 elements
Step 4 → 2 elements
Step 5 → 1 element → found!

Only 5 steps for 16 elements!
1,000,000 elements → only ~20 steps!
```

### Dry Run:
```
arr=[2,4,6,8,10,12,14], target=10
     0 1 2 3  4  5  6

Step 1: left=0, right=6
  mid=3 → arr[3]=8 < 10 → left=4

Step 2: left=4, right=6
  mid=5 → arr[5]=12 > 10 → right=4

Step 3: left=4, right=4
  mid=4 → arr[4]=10 == 10 → return 4 ✅
```

### When to use Binary Search:
```
✅ Array is sorted
✅ Finding specific element
✅ Finding insertion position
✅ Finding first/last occurrence
✅ Any time "search in sorted array"
```

### Interview Answer:
"Binary search works on sorted arrays by repeatedly
halving the search space. Compare target with middle
element — if equal found, if less search left half,
if greater search right half. Time complexity O(log n)
vs O(n) linear search. Key condition: array must be
sorted. Template: left=0, right=len-1, mid=(l+r)//2."

## 2. LeetCode — Binary Search (LC 704)

### Problem:
Given sorted array and target, return index of target.
Return -1 if not found.

```
Input:  nums=[-1,0,3,5,9,12], target=9
Output: 4
```

### Solution:
```python
class Solution:
    def search(self, nums, target):
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return -1
```

**Time Complexity:** O(log n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

## 3. LeetCode — Search Insert Position (LC 35)

### Problem:
Given sorted array and target, return index if found.
If not found — return index where it would be inserted.

```
Input:  [1,3,5,6], target=2 → Output: 1
Input:  [1,3,5,6], target=7 → Output: 4
Input:  [1,3,5,6], target=0 → Output: 0
```

### Key insight:
```
Regular Binary Search → return -1 if not found
Search Insert Position → return LEFT if not found!

When loop ends → left is exactly where
                 target should be inserted!
```

### Why left works:
```
arr=[1,3,5,6], target=2

left=0, right=3
mid=1 → arr[1]=3 > 2 → right=0
left=0, right=0
mid=0 → arr[0]=1 < 2 → left=1
left=1 > right=0 → loop ends!

return left=1 ✅
Insert 2 at index 1 → [1,2,3,5,6] ✅
```

### Solution — ONE LINE CHANGE from Binary Search!:
```python
class Solution:
    def searchInsert(self, nums, target):
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return left  # ← only change from binary search!
```

**Time Complexity:** O(log n)
**Space Complexity:** O(1)
**Result: ACCEPTED ✅**

### Key difference:
```
Binary Search        → return -1  (not found)
Search Insert Pos    → return left (insert here)
```

## Interview Questions and Answers

**Q: What is Binary Search?**
A: Binary search finds target in sorted array by
repeatedly halving search space. Compare with middle
— if equal found, if less search left, if greater
search right. O(log n) time vs O(n) linear. Requires
sorted array.

**Q: What is the time complexity of Binary Search?**
A: O(log n) time, O(1) space. Each step halves the
search space. For 1 million elements — only ~20 steps.
Much faster than O(n) linear search.

**Q: What happens when target is not found in
Search Insert Position?**
A: When while loop ends, left pointer is exactly at
the position where target should be inserted. This is
because left always moves past elements smaller than
target, ending at the correct insertion point.

**Q: What is the difference between Binary Search
and Search Insert Position?**
A: Almost identical — only difference is the return
value when target not found. Binary search returns -1.
Search insert position returns left pointer which
gives correct insertion index.
