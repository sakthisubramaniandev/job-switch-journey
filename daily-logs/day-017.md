## 1. Binary Search Tree (BST)

### What is a BST?
A special binary tree with one powerful rule:
```
For EVERY node:
Left child  → SMALLER than current node
Right child → LARGER than current node
```

### Visual:
```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13
```

### Verify BST property:
```
Node 8  → left=3  (3<8  ✅) right=10 (10>8  ✅)
Node 3  → left=1  (1<3  ✅) right=6  (6>3   ✅)
Node 10 → left=None        right=14 (14>10 ✅)
```

### Why BST is powerful:
```
Regular Binary Tree → search O(n) — check every node
BST                 → search O(log n) — like binary search!

At each node you KNOW which direction to go!
target < node → go LEFT  (target is smaller)
target > node → go RIGHT (target is larger)
```

### Special property — Inorder gives SORTED output:
```
        5
       / \
      3   7
     / \
    2   4

Inorder (Left→Root→Right):
2 → 3 → 4 → 5 → 7 ← SORTED! ✅

Always true for any BST!
Used in many interview problems!
```

### Searching in BST:
```
Find 6 in BST:
        8
       / \
      3   10
     / \
    1   6

Start at 8: 6 < 8 → go LEFT
At 3:       6 > 3 → go RIGHT
At 6:       6 == 6 → FOUND! ✅

Only 3 steps instead of checking all 5 nodes!
```

### BST Search Code:
```python
def search(root, target):
    if not root:
        return None       # not found

    if root.val == target:
        return root       # found!

    if target < root.val:
        return search(root.left, target)   # go left
    else:
        return search(root.right, target)  # go right
```

### BST Insert Code:
```python
def insert(root, val):
    if not root:
        return TreeNode(val)   # insert here!

    if val < root.val:
        root.left = insert(root.left, val)
    else:
        root.right = insert(root.right, val)

    return root
```

### Insert example:
```
Insert 6 into:
        5
       / \
      3   7
     / \
    2   4

6 > 5 → go right to 7
6 < 7 → go left of 7 → insert here!

Result:
        5
       / \
      3   7
     / \ /
    2  4 6
```

### BST vs Regular Binary Tree:
| | Binary Tree | BST |
|---|---|---|
| Structure | Any order | Left<Node<Right |
| Search | O(n) | O(log n) |
| Inorder | Random | Sorted! |
| Insert | Any position | Specific position |

### Real world uses:
```
Database indexes  → fast search
Autocomplete      → word suggestions
File systems      → organized storage
```

### Interview Answer:
"BST is binary tree where left child is always
smaller and right child always larger than parent.
Enables O(log n) search by eliminating half the
tree at each step. Inorder traversal gives sorted
output. Used for database indexes and fast lookups."

## 2. LeetCode — Search in BST (LC 700)

### Problem:
Given root of BST and integer val, find node
with value val. Return subtree rooted at that node.

```
        4
       / \
      2   7
     / \
    1   3

Search val=2 → return subtree:
      2
     / \
    1   3
```

### Key insight — use BST property:
```
val < root.val → search LEFT (val is smaller)
val > root.val → search RIGHT (val is larger)
val == root.val → return root (found!)
```

### Common mistake (made today!):
```python
# WRONG direction!
if root.val < val:
    return search(root.left, val)   # ❌ wrong side!

# CORRECT:
if root.val < val:
    return search(root.right, val)  # ✅ val is bigger → go right!
```

### Solution:
```python
class Solution:
    def searchBST(self, root, val):
        if not root:
            return None         # not found

        if root.val == val:
            return root         # found! return node itself

        if root.val < val:
            return self.searchBST(root.right, val)  # go right
        else:
            return self.searchBST(root.left, val)   # go left
```

**Time Complexity:** O(log n) average, O(n) worst
**Space Complexity:** O(h)
**Result: ACCEPTED ✅**

### Dry Run:
```
        4
       / \
      2   7
     / \
    1   3

Search val=2:
root=4: 4>2 → go left
root=2: 2==2 → return node(2) ✅
```

## 3. LeetCode — Lowest Common Ancestor of BST (LC 235)

### Problem:
Find lowest common ancestor (LCA) of two nodes p and q.
LCA = deepest node that is ancestor of both!

```
        6
       / \
      2   8
     / \ / \
    0  4 7  9
      / \
     3   5

LCA(2, 8) = 6  (root is ancestor of both)
LCA(2, 4) = 2  (2 is ancestor of 4!)
LCA(0, 5) = 2  (2 is ancestor of both)
```

### Key insight — BST property makes it easy!:
```
Both p,q < root → LCA is in LEFT subtree
Both p,q > root → LCA is in RIGHT subtree
Otherwise       → root IS the LCA!

"Otherwise" means:
- p is on left, q is on right (root separates them)
- or one of them IS the root
```

### Solution — solved completely independently! 🔥:
```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        # both smaller → LCA in left subtree
        if p.val < root.val and q.val < root.val:
            return self.lowestCommonAncestor(root.left, p, q)

        # both larger → LCA in right subtree
        if p.val > root.val and q.val > root.val:
            return self.lowestCommonAncestor(root.right, p, q)

        # otherwise → current root is LCA!
        else:
            return root
```

**Time Complexity:** O(log n) average
**Space Complexity:** O(h)
**Result: ACCEPTED ✅**

### Dry Run:
```
        6
       / \
      2   8
     / \
    0   4

LCA(0, 4):
root=6: 0<6 and 4<6 → go left
root=2: 0<2 but 4>2 → return root=2 ✅

LCA(2, 8):
root=6: 2<6 but 8>6 → return root=6 ✅
```

### Why BST makes LCA easier than regular tree:
```
Regular tree LCA → need to check both subtrees
                   complex algorithm
BST LCA          → use BST property to decide
                   direction at each step
                   much simpler!
```

### Interview Answer:
"In BST, LCA uses the BST property. If both nodes
are less than root — LCA is in left subtree. If
both greater — LCA is in right subtree. Otherwise
current root is the LCA since nodes are on different
sides. O(log n) time average."

## Interview Questions and Answers

**Q: What is a Binary Search Tree?**
A: BST is binary tree where left child is always
smaller and right child always larger than parent.
Enables O(log n) search. Inorder gives sorted output.
Used for fast lookups and database indexes.

**Q: How do you search in a BST?**
A: Compare target with current node. If equal return
node. If target smaller go left. If target larger go
right. Repeat until found or reach None. O(log n)
average time — eliminates half tree at each step.

**Q: What is LCA in a BST?**
A: Lowest Common Ancestor is deepest node that is
ancestor of both given nodes. In BST use property:
both nodes less than root → go left, both greater →
go right, otherwise current root is LCA. O(log n).

**Q: What is special about inorder traversal of BST?**
A: Inorder traversal (Left→Root→Right) of BST always
produces sorted output in ascending order. Used to
check if tree is valid BST and to get kth smallest
element problems.
